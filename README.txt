This is a remaster and continuation of the classic GameMode for Pokémon 3D 0.61.2+, based on the famous Pokémon Lost Silver creepypasta and the fangames by Reidd Maxwell.

[Installation Instructions]
1.	Download the LostSilver.zip file from https://github.com/JappaWakka/LostSilver3DRemastered/releases/latest

2.	Open the .zip file using Winrar or 7Zip and extract the "GameModes" and "Save" folder
	into the directory where you've installed Pokémon 3D, overwriting the existing folders.
	
3.	Be sure that there are no ContentPacks active while playing through this GameMode.

4.	Then, start the game and load the save file with "..." as the player name.

To get the good ending, you need to find all 4 secret paths.

Here are some hints to find them:

Secret Path 1: No No No No No
Secret Path 2: DIEDHE
Secret Path 3: Red Pillar
Secret Path 4: Into the Darkness

If you can't figure out what the hints mean (I don't blame you), check the text file "Secret Path Hints Explanation" in the zip.
That should at least give you some more information.
Have fun and be careful not to get too spooked!
